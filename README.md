## Intelligent Fault Prediction & Predictive Maintenance System

### Machine Learning | Industrial AI | Predictive Analytics

## Overview

Developed a web-based Machine Learning application designed to identify potential industrial equipment failures and support proactive maintenance. The system combines a Python-based Random Forest classification model with physics-based diagnostic rules to analyse machine operating parameters, assess equipment health, and generate actionable diagnostic insights.

The application integrates a Flask backend with an interactive JavaScript dashboard, providing equipment monitoring, fault visualization, and automated diagnostic reporting.

## Key Features

- **Machine Learning-Based Prediction:** Random Forest classification for identifying potential equipment failures.
- **Physics-Based Diagnostics:** Engineering-rule-based detection of abnormal operating conditions, including heat dissipation, power, overstrain, and tool wear failures.
- **Equipment Health Monitoring:** Interactive dashboard displaying machine parameters and health indicators.
- **Automated Diagnostic Reports:** Fault severity assessment, diagnostic explanations, and maintenance recommendations.
- **CSV Batch Analysis:** Upload and analyse machine datasets for fleet-level health assessment.
- **Data Visualization:** Interactive charts, gauges, and equipment performance analytics.

## Technology Stack

**Backend & ML:** Python, Flask, Scikit-learn, Pandas, NumPy

**Frontend:** HTML, CSS, JavaScript

**Visualization:** Chart.js
